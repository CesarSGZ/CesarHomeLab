CRIBA DE CONFIGURACIONESPICO GPU ESTIMADO · MENOR ES MEJOR
¿Qué significa “screening”?

Es una preselección para evitar desmontar la caja a ciegas. El modelo GPU calcula un intervalo plausible de temperatura máxima para cada cambio. Un rango como 77.0–79.1 °C significa que esperamos que el pico quede dentro de ese intervalo si la mejora de flujo asumida es real.

Referencia: el modelo reproduce 80.3 °C para la configuración actual. Estos números todavía no son mediciones de las configuraciones nuevas ni resultados CFD.
