Thermal Lab · Fractal Terra

How hot does a 10-litre PC get, and what would actually cool it?

I load the CPU and GPU in controlled tests, turn the measurements into a small physical model, and use that model to rank airflow changes before building any of them. It is the same loop used for engine-bay thermal integration, at desk scale.

  • 7 load tests
  • 4 models built
  • 1 validated
  • CFG-000 baseline · 26.5 °C room
  1. ✓Measure

    Load tests logging temperature, power and fan speed.

  2. ✓Model

    Fit a heat model, then test it on data it never saw.

  3. ✓Rank ideas

    Predict how much each airflow change could help.

  4. 4Prove it

    Build the best idea and A/B test it on the real PC.

  5. 5CFD

    Simulate the airflow once the inputs are trustworthy.

02

How the heat is modelled

Not a black box and not a full simulation: a small thermal circuit with four physical numbers.

Read it like water tanks. Power pours heat into the chip and it drains through the cooler to the room. The tanks (C) set how fast temperatures rise and fall; the pipes (R) set where they settle. Faster fans widen the last pipe.

  1. 1 · Fitthe four numbers to one test.
  2. 2 · Predicta different test without re-fitting.
  3. 3 · Trustit only if the prediction lands close.
03

Which models can be trusted

Each model was judged on a test it had never seen. Shape match: how much of the curve it reproduces (100% is perfect). Typical error: average gap in °C.

    06

    Next steps

    From a validated GPU model to a proven hardware change, then CFD.

    1. ✓
      Close the unknowns

      Done 31 Oct: every part identified and the key gaps derived. Still estimated: cable bundle, top-fan position, panel open area, PSU exhaust direction.

    2. 2
      Repeat the baseline 3×

      Same idle, load and cool-down each time, to learn the normal run-to-run scatter.

    3. 3
      A/B test the best idea

      Baseline → modification → baseline, three runs each. Add one air-temperature sensor inside the case.

    4. 4
      Check the prediction

      Did the measured change land inside the predicted range? Re-fit without the test data and decide.

    Ready for CFD when…

    • Parts, fan specs and key gaps documented
    • Panel open area and grille pressure loss
    • Repeated peaks agree within ±1 °C
    • GPU model error below 2 °C
    • CPU model passes on CPU-only and combined load (< 3 °C)

    CFD then answers the spatial questions: where hot air recirculates and which fan layout deserves a rebuild.

    07

    What it is good for

    FOR THIS PCChange only what works.

    Know roughly how many degrees each modification is worth before cutting, printing or buying anything.

    AS A METHODEngine-bay thinking.

    Controlled configuration, measured boundary conditions, fast reduced-order models and CFD only where it adds value, as in engine–nacelle integration.

    AS EVIDENCEA “no” is a result.

    Rejected models show exactly which measurement is missing, instead of producing confident but unsupported predictions.
