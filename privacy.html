Private workspace, clear boundaries.

HomeLab uses a secure session cookie to authenticate your account. Account records, operational status and private chat history are stored in Cloudflare D1.

AI Chat

Only the authorised owner can use AI Chat. Messages and a limited recent conversation context are sent to the OpenAI API when you submit a message. Responses are saved in HomeLab so you can continue from another device. This does not connect to your ChatGPT account or retrieve its history.

An API key entered in HomeLab is encrypted server-side and is not sent back to the browser. Disconnecting removes the saved key; deleting a conversation removes its messages from the active HomeLab database. Provider-side retention is governed by OpenAI's API data controls. Requests use store:false; this does not imply zero provider retention.

No chat commands can operate your servers. Do not enter passwords, API keys or sensitive personal information in messages. Contact: cesarsollagonzalez@gmail.com.
