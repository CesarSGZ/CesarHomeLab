Private workspace boundaries

HomeLab uses a secure session cookie. Account records and operational state are stored in Cloudflare D1.

ChatGPT Remote

Only CesarVapor can access the dedicated ChatGPT browser running on CesarPC. Browser cookies remain in that separate local profile. Screen images and input events travel through an authenticated Cloudflare relay; the application does not record or persist them. This is transport encryption, not end-to-end encryption against the relay operator.

Your ChatGPT conversations remain governed by your ChatGPT account settings. No API key is required. The remote interface does not share your whole desktop, local filesystem, microphone or system clipboard. Files you explicitly select using Upload file are transferred through the relay and attached to ChatGPT. The app holds transfers in bounded memory and does not write temporary upload files; ChatGPT retention settings still apply. Authentication may need renewing locally on CesarPC. Use only trusted devices and sign out of HomeLab when finished.
